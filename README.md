Discrete Mathematics with Python
This project is a comprehensive collection of Python functions that address fundamental concepts and problems from discrete mathematics. Designed primarily for students and enthusiasts, it transforms theoretical ideas from assignments and textbooks into practical, hands-on code.

Features
Covers classic discrete math topics: number theory, logic, combinatorics, modular arithmetic, sequences, and graph-theoretical concepts.

Functions include factorial calculation, palindromes, divisor and prime analysis, digital roots, sequence generators, modular inverses, and more.

Clearly organized code with function-level explanations for each mathematical concept.

Suitable for assignment support, exam revision, or as a study companion to university-level discrete mathematics courses.

Example Topics
Factorials and digit operations

Prime factorization and prime-related functions

Special number types (abundant, deficient, automorphic, pronic, Harshad, Mersenne, Fibonacci, perfect power, Carmichael, highly composite)

Divisor functions (sum, count, aliquot sum, amicable numbers)

Sequence generation (Lucas, polygonal)

Modular arithmetic (modular exponentiation, modular inverse, Chinese Remainder Theorem, quadratic residues, orders)

Famous algorithms (Miller-Rabin primality, Pollard’s Rho, Collatz sequence)

Approximations and partitions (zeta function, integer partition)

Purpose
The project provides accessible, working code to reinforce classroom concepts, support self-study, and enable computational exploration of discrete mathematics. Each function is implemented with readability and practical utility in mind, encouraging experimentation and deeper understanding.

Feel free to explore the source code, use the functions in your own projects, or contribute improvements and new features!
